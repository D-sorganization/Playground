## Feature Details

### Repeat last set (⟳)
- "⟳" button added to every `renderSetRow` in app.js
- Pre-fills exercise name, reps, weight from that set into the quick-add form
- Triggers `refreshLastSession` for the exercise

### Plate calculator modal
- `calcPlates(target, bar, unit)` — greedy descent over standard lbs/kg plate sizes
- Accessible via ⚖ button in timer strip; pre-fills from current weight input
- Shows per-side plate breakdown; error message for impossible weights

### Quick weight ± buttons
- −5, −2.5, +2.5, +5, +10 buttons below weight input
- `bindWeightAdj()` handles delta arithmetic with floor at 0

### Rest timer + session timer
- Session timer: starts on `startWorkout()` / `tryResumeActive()`; count-up display
- Rest timer: resets and starts on every set execute (✓ button or `addSet(executed=true)`)
- Both displayed in persistent timer strip above quick-add card

### Screen Wake Lock
- Acquired on `startWorkout()` and `tryResumeActive()`; released on `finishWorkout()`
- Re-acquired on `visibilitychange` if page becomes visible again during active workout
- Silent error handling for unsupported browsers / denied permissions

### Last-session recall
- Backend: `GET /api/last_session_sets?exercise_name=X` returns sets from the most recent workout date that has executed sets for that exercise
- Frontend: clickable chips above exercise input; click fills reps+weight
- Triggered on `pickSuggestion`, repeat-set click, and voice input

### Voice input
- `webkitSpeechRecognition` — gracefully disabled when browser doesn't support it
- Parses "exercise N by W", "exercise N x W", "exercise N reps W" patterns
- Fills exercise/reps/weight fields; falls back to setting exercise name only

## Known Limitations

- Voice recognition quality depends on browser/OS; Chrome-only for `webkitSpeechRecognition`
- Plate calculator uses standard barbell sizes only (no fractional plates beyond 2.5 lbs / 1.25 kg)
- Wake lock requires HTTPS in production (localhost works in development)
