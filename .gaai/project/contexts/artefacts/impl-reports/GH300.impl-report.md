# GH300 Implementation Report

## Summary

Implemented three features for the workout tracker following TDD (tests written first, then implementation):

1. **Exercise Aliases** — DB table, dataclass, repo methods, and API routes for managing per-exercise aliases with alias-boosted autocomplete.
2. **History Search/Filter** — `search_workouts()` repo method and `GET /api/workouts/search` route with dynamic WHERE clause, date/status validation, and implicit LIMIT 200.
3. **Multi-word Autocomplete** — Updated `suggest()` to handle multi-word queries (all tokens must appear as substrings in normalized exercise name) and apply +6000 alias boost via `alias_resolver` callback.

## Files Modified

### `src/workout_tracker/schema.sql`
- Appended `exercise_aliases` table (id, exercise_id, alias, normalized_alias, created_at) with `ON DELETE CASCADE` FK to exercises.
- Added two indexes: `idx_aliases_exercise` and `idx_aliases_normalized`.

### `src/workout_tracker/models.py`
- Added `ExerciseAlias` frozen dataclass with `__post_init__` auto-normalization and `to_dict()`.

### `src/workout_tracker/db.py`
- Imported `VALID_STATUSES` and `ExerciseAlias` from models.
- Added alias methods: `add_alias`, `delete_alias`, `list_aliases`, `resolve_alias`, `_row_to_alias` (static).
- Added `search_workouts(exercise_name?, date_from?, date_to?, min_weight?, status?)` with dynamic WHERE clause, `# noqa: S608` on the SQL line, status validation, and LIMIT 200.

### `src/workout_tracker/autocomplete.py`
- Added `from collections.abc import Callable` import.
- Updated `suggest()` signature with `alias_resolver: Callable[[str], Exercise | None] | None = None`.
- Multi-word path: split tokens, require all tokens as substrings of `normalized_name`.
- Alias resolver: applied +6000 boost to matching exercise before scoring loop.

### `src/workout_tracker/app.py`
- Updated `/api/exercises/suggest` to pass `alias_resolver=repo.resolve_alias`.
- Added alias routes: `POST /api/exercises/<ex_id>/aliases`, `GET /api/exercises/<ex_id>/aliases`, `DELETE /api/aliases/<alias_id>`.
- Added `GET /api/workouts/search` route registered **before** `GET /api/workouts/<int:w_id>` with date validation via `date.fromisoformat()` and error handling.

### `tests/test_workout_tracker_db.py`
- Added `TestAliasRepo` (7 tests): add, normalize, resolve, resolve unknown, delete, unique constraint, cascade delete.
- Added `TestSearchWorkouts` (8 tests): all, date_from, date_to, status, exercise_name, min_weight, invalid status raises, limit.
- Added `ExerciseAlias` import.

### `tests/test_workout_tracker_autocomplete.py`
- Added `TestSuggestMultiword` (3 tests): all-token requirement, no-match, single-word unaffected.
- Added `TestSuggestAliasResolver` (3 tests): alias boost promotes exercise, no resolver works normally, None resolver no crash.

### `tests/test_workout_tracker_app.py`
- Added `TestAliasRoutes` (4 tests): add+list, delete, missing body 400, suggest with alias.
- Added `TestWorkoutSearchRoute` (6 tests): search all, by status, by date range, invalid status 400, invalid date 400, search route not confused with workout-id route.
