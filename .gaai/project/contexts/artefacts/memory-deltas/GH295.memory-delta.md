# GH295 Memory Delta

## New Patterns Worth Persisting

### Pattern: Browser Wake Lock lifecycle
- Acquire on workout start (both new start and session resume)
- Release on workout finish
- Re-acquire on `document.visibilitychange` → `visible` during active workout
- Silent error handling — no user-visible disruption on unsupported browsers

### Pattern: Timer infrastructure in vanilla JS SPA
- Session timer: `setInterval` reference stored in state, cleared on finish/showEmpty
- Rest timer: same pattern, reset on every "execute" action
- `fmtDuration(secs)` → `M:SS` format

### Pattern: Last-session recall via dedicated endpoint
- `GET /api/last_session_sets?exercise_name=X` — returns sets from the **most recent date** that has executed sets for that exercise
- Two new repo methods: `resolve_exercise_by_name(name)` (normalized lookup) + `last_session_sets(exercise_id, limit)` (date-scoped query)

### Pattern: Plate calculator — greedy descent
- Standard lbs sizes: [45, 35, 25, 10, 5, 2.5]
- Standard kg sizes: [20, 15, 10, 5, 2.5, 1.25]
- Returns None when the weight cannot be made exactly
- Implemented in JS (frontend) with a Python port in tests

### Pattern: Voice input — graceful degradation
- Check `window.SpeechRecognition || window.webkitSpeechRecognition` before binding
- Disable button if unavailable — no error thrown
- Pattern regex: `^(.+?)\s+(\d+)\s+(?:by|x|reps?|×)\s+([\d.]+)`

## No Architectural Decisions Emerged

All patterns above are implementation-level. No new services, paradigm shifts, or stack additions introduced.
