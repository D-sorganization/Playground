# MyoSim - Golf Swing Simulation

MyoSim is a high-fidelity biomechanical simulation interface for modeling the golf swing using MuJoCo.

## Features

- **MuJoCo Integration**: Real-time physics simulation using MuJoCo.
- **Golf Swing Analysis**: Tools for modeling forces and control aspects.
- **Data Visualization**: Real-time plotting of simulation data.

## Installation

1. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the main application:

```bash
python -m myosim.main
```
