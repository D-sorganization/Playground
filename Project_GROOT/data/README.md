# Data Directory

This directory contains all data for Project GROOT pipeline.

## Structure

```
data/
├── raw_video/           # Input golf swing videos
├── processed_pose/      # Extracted pose sequences (.npz)
├── retargeted_demos/    # Robot joint trajectories (.npz)
├── pose_models/         # Pre-trained pose estimation models
└── manifest*.json       # Video manifests
```

## Data Format Specifications

### Raw Video
- **Format**: MP4, AVI, MOV
- **Resolution**: 720p or higher recommended
- **Frame Rate**: 30 fps or higher
- **Duration**: 2-5 seconds per swing
- **Camera Angle**: Side view (sagittal plane) works best

### Processed Pose (.npz)
Generated by `tools/pose_convert.py`

Contains:
- `skeleton`: (T, 33, 3) - xyz positions of body keypoints
- `skeleton_confidence`: (T, 33) - detection confidence per joint
- `timestamps`: (T,) - frame timestamps in seconds
- `phase_labels`: (T,) - swing phase labels (0-4)
- `club_grip`: (T, 3) - club grip position
- `club_head`: (T, 3) - clubhead position
- `club_face`: (T, 3) - clubface normal vector
- `club_speed`: (T,) - clubhead speed in m/s

### Retargeted Demos (.npz)
Generated by `tools/retarget_to_sim.py`

Contains:
- `q`: (T, num_dofs) - joint positions in radians
- `qdot`: (T, num_dofs) - joint velocities in rad/s
- `qddot`: (T, num_dofs) - joint accelerations in rad/s²
- `ee_pos`: (T, 3) - end-effector (clubhead) position in meters
- `timestamps`: (T,) - frame timestamps
- `dof_names`: List of DOF names

## Data Collection Tips

### Video Recording
1. Use side view (perpendicular to swing plane)
2. Ensure good lighting (avoid shadows)
3. Capture full body (head to feet)
4. Keep camera stationary
5. Include backswing, downswing, and follow-through
6. Avoid occlusions (club should be visible)

### Video Sources
- YouTube golf instruction videos
- Pro tournament footage
- Personal recordings
- Golf simulators

### Quality Checklist
- [ ] Full body visible
- [ ] Side view angle
- [ ] Good lighting
- [ ] Club visible throughout
- [ ] Minimal background clutter
- [ ] Stable camera
- [ ] At least 720p resolution

## Data Management

### Storage Requirements
- Raw video: ~10-50 MB per swing
- Processed pose: ~100-500 KB per swing
- Retargeted demos: ~50-200 KB per swing

For 100 swings:
- Total: ~1-5 GB

### Backup
Recommended to backup:
- `raw_video/` - Source data
- `manifest*.json` - Video metadata
- `retargeted_demos/` - Processed training data

### Cleaning
To clean generated data:

```bash
# Clean processed data (keeps raw videos)
rm -rf data/processed_pose/*
rm -rf data/retargeted_demos/*
rm -f data/manifest*.json

# Full clean (WARNING: deletes everything)
# rm -rf data/*
```
